" Learn CSS: Typography

" -----------------------------------------------------------------------------
" What is Typography?
" -----------------------------------------------------------------------------

" Typography is the art of arranging and styling text on a web page.
"
" Good typography improves:
"   • Readability
"   • Accessibility
"   • User experience (UX)
"   • Visual hierarchy

" Since most websites communicate through text, learning typography is an
" essential CSS skill.

" -----------------------------------------------------------------------------
" In This Lesson
" -----------------------------------------------------------------------------

" You will learn how to:

" 1. Style fonts
"    - Change font family
"    - Adjust font size
"    - Modify font weight
"    - Change font style

" 2. Transform text
"    - Uppercase
"    - Lowercase
"    - Capitalize
"    - Other text formatting

" 3. Control text layout
"    - Alignment
"    - Spacing
"    - Line height
"    - Letter spacing

" 4. Add external fonts
"    - Import fonts from services like Google Fonts
"    - Use custom fonts in your website

" -----------------------------------------------------------------------------
" Why Typography Matters
" -----------------------------------------------------------------------------

" Text is often the most important content on a webpage.

" Proper typography makes content:
"
" ✓ Easier to read
" ✓ More accessible
" ✓ More visually appealing
" ✓ Better organized
" ✓ More engaging for users

" Poor typography can make even excellent content difficult to read.

" -----------------------------------------------------------------------------
" Key Takeaway
" -----------------------------------------------------------------------------

" CSS gives developers complete control over how text appears on a webpage.

" Throughout this lesson you'll learn how to:
"
" • Style fonts
" • Arrange text
" • Improve readability
" • Use custom fonts
"
" These skills are fundamental for creating professional-looking websites.
