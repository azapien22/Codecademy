HTML Elements Cheat Sheet

A quick reference guide for commonly used HTML tags and attributes.

HTML Document Structure

Element Formatted Tag Description
HTML <html> Contains all of the HTML content on a webpage.
Head <head> Contains page information that is not displayed as main page content.
Title <title> Sets the webpage title shown in the browser tab.
Body <body> Contains the visible content of the webpage.

Text and Content Elements

Element Formatted Tag Description
Heading <h1> through <h6> Creates headings. The <h1> element is the most important heading.
Paragraph <p> Creates a paragraph of text.
Division <div> Groups related content into a block-level container.
Span <span> Groups a small portion of inline content for styling or scripting.
Line Break <br> Creates a line break within text.
Strong Importance <strong> Marks text as strongly important and usually displays it in bold.
Emphasis <em> Adds emphasis to text and usually displays it in italics.

Links, Images, and Lists

Element Formatted Tag Description
Anchor <a> Creates a hyperlink to another page, file, or location.
Image <img> Embeds an image in the webpage.
Unordered List <ul> Creates a bulleted list.
Ordered List <ol> Creates a numbered list.
List Item <li> Creates an individual item inside an ordered or unordered list.

Common HTML Attributes

Attribute Example Description
class class="card" Assigns one or more reusable CSS class names to an element.
id id="main-title" Assigns a unique identifier to an element.
href href="https://example.com" Specifies the destination of an anchor element.
src src="image.jpg" Specifies the source file for an image or other embedded content.
alt alt="Description of image" Provides alternative text that describes an image.
