# HTML Elements Cheat Sheet

A Codecademy Web Development Foundations challenge project.

## Project requirements met

- Documents an HTML topic.
- Uses HTML tables for the documentation.
- Labels every table column with table headings.
- Uses a custom CSS color scheme.
- Styles code examples with a monospace font and a different background color.
- Includes responsive styling for smaller screens.

## Files

- `index.html` — webpage structure and cheat sheet content
- `styles.css` — colors, tables, typography, code styling, and responsive layout

## Run the project

Open `index.html` in a web browser.
